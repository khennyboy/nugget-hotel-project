# Nugget Continental Hotel & Tours

A responsive hotel and tourism website for Nugget Continental Hotel & Tours.

## About the Project

Nugget Continental Hotel & Tours is a hotel management and booking website designed to allow guests to explore available rooms, restaurant services, tour packages, and other hotel information.

The project focuses on creating a clean, responsive, and user-friendly experience for hotel guests.

## Features

- Responsive navigation
- Hotel room listings
- Room details and pricing
- Restaurant information
- Tour packages
- Booking interface
- Responsive design for mobile, tablet, and desktop
- Responsive images using `srcSet`
- Animated mobile navigation

## Technologies Used

- React
- TypeScript
- React Router
- Tailwind CSS
- Motion
- React Icons
- Vite
